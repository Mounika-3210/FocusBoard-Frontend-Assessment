# Screenshot checklist

The assessment asks for one desktop screenshot and one mobile screenshot. Capture these after running the app:

- Desktop: 1440 × 1000 (dashboard overview and task list)
- Mobile: 390 × 1128 (responsive dashboard)

Suggested Windows capture: open the app in Chrome, set device dimensions in DevTools (Ctrl+Shift+M), then capture with the OS screenshot tool. Keep screenshots in this folder and add them to the repository before submitting.
